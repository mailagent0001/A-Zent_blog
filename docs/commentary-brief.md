# 都道府県ページの解説文 作成指示書(別AI向け)

## 目的
A-Zent(沖縄の個人事業。IT導入・DX支援・業務自動化)のサイトにある、都道府県別の統計ページ(/stats/<県>/)に載せる解説文を、県ごとに書く。
- 読む人: その県で、業務効率化やDXを考えている企業の担当者
- 位置づけ: 公的統計(e-Stat)を、出典付きで見せるページ。営業ページではない
- サイトは開業準備中。契約・有償サービス・料金・営業を思わせる表現は使わない

## 入力(1県につき1つ)
`node scripts/print_facts.mjs <slug> <slug>…` の出力(事実シート)。例: `node scripts/print_facts.mjs okinawa aomori tokyo`(1回に3〜5県が目安)
- 各行: id | 項目名 | 値 | 47都道府県の平均(mean47) | 比(ratio=値÷平均) | 順位(1位が最大) | 調査年
- 平均は「47都道府県の単純平均」(全国の合計値ではない)。文中では「47都道府県の平均」と書く
- highlights は、その県の特徴の候補(平均との差が大きい項目)
- 調査年が項目ごとに違う(人口2020年度、事業所2021年度、収入2019年度、余暇2021年度など)。数字を書くときは、調査年も書く

## 出力(複数の県をまとめて、1つのJSONで出す)
```
{ "okinawa": { "summary": "…", "insights": ["…","…"], "faq": [ {"q":"…","a":"…"}, {"q":"…","a":"…"} ] }, "aomori": { … } }
```
- キーは、県の英字名(slug)。JSONだけを出す(説明文や ``` は付けない)
- 保存は、人が `node scripts/split_commentary.mjs batch.json` で行う(県ごとの data/commentary/<slug>.json に分かれる)

## 1県ぶんの中身
- summary: 120〜160字 / insights: 2〜3本 / faq: 2問(q と a)
- 見本: docs/commentary-sample-okinawa.json(形・長さ・言い回しの基準)
- insights の各本は、「【データから言えること】」(事実)のあとに、必要なら「【一般的な見方】」(推測)を続ける。推測には「(一般的な見方であり、個別の会社の状況は異なります)」を付ける
- faq は2問。1問は、その県のデータに関する問い。もう1問は、オンライン相談・準備中の説明など

## 守ること
1. 事実シートにない数字・地名・名所・産業・企業名・制度は、書かない
2. 数字は、事実シートの値のまま書く。丸め、足し算、引き算、割合の再計算はしない
3. 項目名の意味を、変えない。付け足さない(例: 「年間収入」を、勝手に「世帯の年間収入」「平均年収」と言い換えない)
4. 順位は「47都道府県中○位」「1位」のように、事実シートの順位を、そのまま使う
5. 因果を断定しない(「〜だから〜になる」は書かない)。推測は「〜と考えられます」と書き、【一般的な見方】の中に置く
6. 使わない言葉: 必ず / 絶対 / No.1 / ナンバーワン / 最安 / 業界最大 / 無料 / 限定 / 今すぐ / 契約してください
7. 沖縄県以外の県を書くとき、沖縄の話(沖縄、A-Zentが沖縄の事業であること)は、書かない
8. 個人情報・個別の企業・個人の話は、書かない

## 県ごとに違う文章にする方法
- 書き出しと切り口は、highlights の上位2〜3項目で決める(県ごとに、取り上げる項目が変わる)
- 同じ型の言い回しを、県をまたいで繰り返さない。書き出しの型を、3種類以上、使い分ける
  - 型A: 順位から入る(例: 「○○県は、△△の割合が47都道府県中1位です」)
  - 型B: 平均との差から入る(例: 「△△は□□%で、47都道府県の平均◇◇%を、上回ります」)
  - 型C: 項目どうしの対比から入る(例: 「△△は高い一方で、□□は低い傾向です」)
- 平均との差が小さい項目(ratio が0.95〜1.05)は、特徴として取り上げない
- 「小規模事業所が多い」「高齢化が進んでいる」などの言い方は、データがそう示すときだけ使う(事業所の割合や65歳以上の割合の、順位と平均で判断する)

## 提出前の検査(必ず実行)
```
node scripts/validate_commentary.mjs
```
- 事実シートにない数字、禁止表現、県どうしの文章の似すぎ(35%超)を検出する
- 「NG」が出たら、その県を直して、再実行する
- 検査が通っても、地名や事実の誤りは見つからない。書いた県の文章は、人が読んで確認する

## 進め方
1. 最初に、沖縄県と2県(例: 青森県・東京都)を書き、人が確認する
2. 確認が済んだら、残りを書く(1回に10県ほど)
3. 書けた県から、公開する(本番は、解説文のある県だけが公開される設定)
